# zakon.rada.gov.ua — URL-шаблони для браузера

Відкривай у браузері (web fetch заблоковано robots.txt).

| Потреба | URL |
|---|---|
| Знайти акт за назвою/абревіатурою | `https://zakon.rada.gov.ua/laws/find/a?text=<назва або абревіатура>` — переадресує на акт або список кандидатів |
| Кілька кандидатів одразу (статус, редакція) | `https://zakon.rada.gov.ua/laws/main/<nreg1>,<nreg2>` |
| Одна стаття (легко, 5–45 КБ) | `https://zakon.rada.gov.ua/laws/show/<nreg>/conv/parast<N>/only.frame` |
| Інша структурна одиниця | `.../conv/para<tree-id>/only.frame` (`pr_1` підрозділ, `rz<N>` розділ, `gl<N>` глава, `cm_<N>` примітка) |
| Зміст акта з маркерами «виключено» | `https://zakon.rada.gov.ua/laws/show/<nreg>/stru.frame` |
| Картка акта (реквізити, статус, редакції) | `https://zakon.rada.gov.ua/laws/card/<nreg>` |
| Редакція на дату | `https://zakon.rada.gov.ua/laws/show/<nreg>/ed<YYYYMMDD>` |
| Весь текст (великі кодекси — лише за потреби) | `https://zakon.rada.gov.ua/laws/show/<nreg>/print` |

Пастки:
- Архівні «двійники»: у назві є «(редакції до …)» — це архів, хоч і зі статусом «Чинний». Відкидай.
  Приклад: КУпАП має три nreg; чинний — той, що без «редакції до» і з найновішою редакцією.
- Не вгадуй nreg із пам'яті. Резолви через `find/a?text=` або web search «zakon.rada.gov.ua "точна назва"»,
  потім перевір карткою.
- Фігурні дужки `{...}` у тексті — службові позначки про зміни, не текст норми. Не цитуй їх як норму.
- Статтю могли виключити: перевір `stru.frame`.
- Конституція: nreg `254к/96-вр` → у URL `254%D0%BA/96-%D0%B2%D1%80` (слеш не кодується).
- Суми «у неоподатковуваних мінімумах»: для адмінштрафів НМДГ = 17 грн (ПКУ, розд. XX, підрозд. 1, п. 5) —
  перевір актуальність і показуй обидві величини.
