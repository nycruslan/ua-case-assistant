# ua-case-assistant — помічник у справі за українським правом

Плагін для Claude Code і Claude Cowork: клієнт і адвокат ведуть одну справу в спільній папці. Десять
скілів українською покривають повний цикл: налаштування → профіль справи → аналіз → хронологія й докази →
строки → проєкти документів → перевірка перед поданням → моніторинг → пояснення клієнту.

**Усі результати — чернетки для перевірки адвокатом, не юридична консультація.** Claude не підписує, не
подає і не надсилає жодного документа: це робить лише людина.

## Встановлення

```
/plugin marketplace add nycruslan/ua-case-assistant
/plugin install ua-case-assistant@ua-legal
```

Далі **перезапусти застосунок** один раз: MCP-сервер плагіна під'єднується на старті сесії, а не через
`/reload-plugins`.

**Увімкни автооновлення**: `/plugin` → **Marketplaces** → `ua-legal` → **Enable auto-update**. Сторонні
маркетплейси за замовчуванням не оновлюються, тож без цього виправлення до тебе не дійдуть. Вручну:
`/plugin marketplace update ua-legal`, потім `/plugin update ua-case-assistant@ua-legal`. Потім запусти `/ua-case-assistant:setup` — він перевірить джерела, запропонує LEXERY і
створить приватну папку справи.

| Компонент | Навіщо | Обов'язково |

| Платний план Claude | плагіни | так |

| Браузер (`/chrome` або браузер Cowork) | судові портали, стан справи (під reCAPTCHA — вручну) | за потреби |

## Інструменти (MCP-сервер `ua-legal-sources`)

Працює локально, використовує мережу цього комп'ютера. Кожна відповідь несе `source_url`, `retrieved_at` і,
для тексту норми, дату редакції.

| Інструмент | Джерело |
|---|---|
| `rada_resolve`, `rada_status`, `rada_unit`, `rada_list_units` | офіційне відкрите API data.rada.gov.ua |
| `lpd_search`, `lpd_position`, `lpd_digest_search` | база правових позицій ВС |
| `edrsr_search`, `edrsr_document` | ЄДРСР |

Стан справи на `court.gov.ua/fair` закритий reCAPTCHA, тому його перевіряє людина — скіл `case-monitor`
дає інструкцію.

Деталі й пастки, які вони закривають (архівні «двійники» кодексів, надрядкові номери статей, виключені
статті й пункти, прикінцеві та перехідні положення, майбутні редакції) — у README репозиторію.

## Які документи він читає

PDF (зокрема скани), фото (JPG, PNG, HEIC з iPhone), Word (DOCX, DOC, RTF, ODT), Excel (XLSX), листи
(EML), скріншоти й експорти месенджерів, ZIP-архіви — вбудованими засобами Claude і системи, нічого
встановлювати не треба. Аудіо й відео Claude прослухати не може: такі файли позначаються «потрібна
розшифровка». Word, RTF і фото HEIC конвертуються засобами macOS; на інших системах їх треба зберегти як
PDF чи JPG.

## Де працює

| Де | Що працює |

| Claude Code (термінал, IDE, вкладка Code у застосунку) | усе: скіли й інструменти |

## Що плагін запускає, надсилає і зберігає

**Запускає.** Локальний MCP-сервер `ua-legal-sources` — один файл `mcp/ua-legal-sources.mjs` (Node.js 20+,
~130 КіБ, без залежностей), зібраний із читабельного коду в репозиторії (`mcp/ua-legal-sources/src`). Його стартує
`scripts/ua-legal-sources.sh`, який лише знаходить Node на комп'ютері. Нічого не встановлює і нічого не
завантажує для запуску.

**З'єднується лише з офіційними державними джерелами, по HTTPS:**

| Хост | Навіщо | Що надсилається |
|---|---|---|
| `data.rada.gov.ua` | тексти й картки законів (відкриті дані ВРУ) | номер акта, дата редакції |
| `zakon.rada.gov.ua` | лише пошук номера акта за назвою | назва чи абревіатура акта |
| `lpd-api-prod.court.gov.ua` | правові позиції та огляди практики ВС | текст пошукового запиту |
| `reyestr.court.gov.ua` | пошук і читання судових рішень (ЄДРСР) | пошуковий запит, номер справи чи ЄРДР, прізвище судді, дати — те, що Claude вказав у запиті |

Пошукові запити формує Claude з вашого питання, тож у них може потрапити, наприклад, номер вашої справи.
Документи справи, файли з теки справи й ваші дані нікуди не надсилаються. Сервер не має телеметрії й не
звертається до серверів автора. Якщо задано `HTTPS_PROXY`, запити йдуть через цей проксі.

**Зберігає.** Тексти законів кешуються на диску (у теці даних плагіна `~/.claude/plugins/data/…/cache`, інакше
`~/.cache/ua-legal-sources`). Судові рішення ЄДРСР на диск не записуються ніколи — лише в пам'яті на час
сесії, бо реєстр виправляє витоки персональних даних, переанонімізуючи той самий документ.

**Ввічливість до джерел.** Пауза 5–7 с між запитами до data.rada, ≥1,1 с до ЄДРСР, не більше 8 рішень на
одне питання, жодного масового завантаження; на капчі чи блокуванні — зупинка, обходу немає.

**Дозволи.** На час ходу, в якому працює скіл, скіли заздалегідь дозволяють інструменти `ua-legal-sources`
(лише читання) та кілька команд для читання файлів справи (`textutil`, `sips`, `unzip -p`, `afinfo`,
`iconv`). Скіли також можуть запускати `python3` зі стандартною бібліотекою, щоб прочитати Excel чи лист —
це запитає дозвіл як звичайно. Дозволи не зберігаються в налаштуваннях.

## Структура папки справи (створює `setup` / `case-setup`)

```
CASE.md  INDEX.md  CHRONOLOGY.md  EVIDENCE.md  DEADLINES.md  LOG.md
00_inbox/  01_documents/  02_court/  03_research/  04_drafts/  05_filed/
```

Матеріали справи ніколи не зберігаються в репозиторії плагіна.

## Принципи

- Жодної норми чи рішення з пам'яті; неперевірене позначається `[НЕ ПЕРЕВІРЕНО]`.
- Claude не підписує, не подає і не надсилає — лише людина.
- Строки — консервативно і «попередньо» до підтвердження адвокатом.
- Спільна папка — джерело істини; записи позначаються `[адвокат]` / `[клієнт]`.
- Порожній результат означає «я не знайшов», а не «цього не існує».

Для Cowork: текст `skills/setup/references/case-folder-CLAUDE.md` вставляється в Project → Instructions.
