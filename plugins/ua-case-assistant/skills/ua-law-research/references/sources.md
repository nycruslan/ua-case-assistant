# Джерела: що де шукати

Позначки доступу: WF = web fetch працює · BR = потрібен браузер · LOGIN = потрібен вхід людини.

## Законодавство
- Законодавство України (офіційне): https://zakon.rada.gov.ua — BR. Єдине джерело для цитування.
- Відкриті дані ВРУ: https://data.rada.gov.ua — для масових вибірок; не для діалогу.
- Законопроєкти (статус, тексти, друге читання): https://itd.rada.gov.ua — BR.
- Неофіційні дзеркала (protocol.ua, urst.com.ua, uristy.ua, kodeksy.com.ua) — лише для орієнтації;
  kodeksy.com.ua має сторінки редакції 2019 року. Ніколи не цитуй із них.

## Судова практика
- ЄДРСР: https://reyestr.court.gov.ua — читання `/Review/<id>` WF; пошук BR. ~137 млн документів; частина
  рішень обмежена або публікується із затримкою.
- База правових позицій ВС: https://lpd.court.gov.ua (BR) · API https://lpd-api-prod.court.gov.ua/api/v1 (GET — WF;
  `/legal-position/<id>`, `/document/<id>`, `/court/list`, `/digest/navigation`). Реєстрація не потрібна.
- Огляди й дайджести практики ВС: https://supreme.court.gov.ua (PDF — WF).
- Конституційний Суд: https://ccu.gov.ua.
- Вищий антикорупційний суд: https://hcac.court.gov.ua.
- ЄСПЛ: https://hudoc.echr.coe.int — BR (JS-застосунок). Переклади рішень щодо України також публікуються на
  zakon.rada.gov.ua.

## Стан справи і суди
- Стан розгляду справ: https://court.gov.ua/fair/ — BR (пошук за номером справи/стороною).
- Електронний суд: https://id.court.gov.ua — LOGIN (id.gov.ua, Дія.Підпис, хмарний підпис). Claude не
  підписує, не подає і не вводить паролі чи ключі; вхід і підпис — лише людина.
- Судовий збір: Закон «Про судовий збір» (ставки — ст. 4; при поданні в електронній формі застосовується
  понижувальний коефіцієнт — перевір чинний текст і прожитковий мінімум на 1 січня поточного року).

## Реєстри (частина обмежена під час воєнного стану — перевіряй доступність)
- ЄДР юросіб і ФОП: https://usr.minjust.gov.ua (BR) або Opendatabot / YouControl (BR, частина платна).
- Виконавчі провадження (АСВП): https://asvpweb.minjust.gov.ua — BR.
- Єдиний реєстр боржників: https://erb.minjust.gov.ua — BR.
- Реєстр речових прав на нерухоме майно: платні витяги (Дія / kap.minjust.gov.ua) — LOGIN; отримує людина.

## Комерційні бази (якщо є підписка — через залогінений Chrome адвоката)
- LIGA360 (у т.ч. версія для адвокатів НААУ), Opendatabot (моніторинг судів, API), YouControl.

- Реакція ВС на зловживання ШІ: справи № 925/200/22 (08.02.2024, КГС ВС), № 925/496/24 (08.07.2025, КГС ВС),
  № 240/14153/24 (15.01.2026, КАС ВС — вигадані посилання на практику).
