# ua-case-assistant — помічник у справі за українським правом

Плагін для Claude Cowork: клієнт і адвокат ведуть одну справу в спільній синхронізованій папці. Дев'ять
скілів українською покривають повний цикл: профіль справи → аналіз → хронологія й докази → строки →
проєкти документів → перевірка перед поданням → моніторинг → пояснення клієнту.

## Що потрібно поруч

| Компонент | Навіщо | Обов'язково |
|---|---|---|
| Claude Desktop з Cowork, платний план | локальна папка, браузер, плагіни | так |
| Claude in Chrome (або вбудований браузер Cowork) | zakon.rada.gov.ua блокує web fetch через robots.txt; пошук у ЄДРСР і стан справи — через форми | так |
| Плагін LEXERY Ukrainian Law (`LEXERY-AI/lexery-ukrainian-law`) | методика перевірки норм, практики ВС і аудиту посилань | рекомендовано |
| Gmail-конектор | повідомлення Електронного суду для моніторингу | за потреби |

## Скіли

| Скіл | Для чого | Приклад запиту |
|---|---|---|
| `case-setup` | інтерв'ю, структура папки, INDEX.md, CASE.md | «/case-setup» |
| `ua-law-research` | як дістатися до джерел з Cowork і перевірити норму/практику | «яка редакція ст. 1270 ЦК чинна?» |
| `case-analysis` | правовий меморандум, ризики, стратегія | «проаналізуй справу» |
| `chronology-evidence` | CHRONOLOGY.md і EVIDENCE.md з джерелами | «побудуй хронологію» |
| `procedural-deadlines` | строки, DEADLINES.md, нагадування/.ics | «до коли подати апеляцію?» |
| `procedural-drafting` | проєкти позовів, скарг, клопотань, запитів (DOCX) | «склади апеляційну скаргу» |
| `pre-filing-check` | аудит посилань, фактів, форми, строків; вердикт | «перевір перед поданням» |
| `case-monitor` | стан справи, нові рішення в ЄДРСР, пошта суду | «що нового у справі?» |
| `client-explainer` | пояснення простою мовою, підготовка до засідання | «що означає ця ухвала?» |

## Структура папки справи (створює `case-setup`)

```
CASE.md  INDEX.md  CHRONOLOGY.md  EVIDENCE.md  DEADLINES.md  LOG.md
00_inbox/  01_documents/  02_court/  03_research/  04_drafts/  05_filed/
```

## Принципи

- Жодної норми чи рішення з пам'яті; неперевірене позначається `[НЕ ПЕРЕВІРЕНО]`.
- Claude не підписує, не подає і не надсилає — лише людина.
- Строки — консервативно і «попередньо» до підтвердження адвокатом.
- Спільна папка — джерело істини; записи позначаються `[адвокат]` / `[клієнт]`.

Інструкції для проєкту Cowork — у `PROJECT_INSTRUCTIONS.md`.

Усі результати — чернетки для перевірки адвокатом, не юридична консультація.
