# Мова і стиль процесуальних документів

- Мова — українська. Терміни — з тексту кодексу (позивач, відповідач, третя особа, підозрюваний,
  обвинувачений, потерпілий, заява по суті справи, клопотання, ухвала, постанова, рішення).
- Одна думка — одне речення; абзаци по 2–5 речень; нумеровані пункти в прохальній частині.
- Дати: «15 березня 2024 року» у тексті; суми: «200 000,00 грн (двісті тисяч гривень 00 копійок)» —
  якщо цього вимагає практика документа.
- Посилання на норму: «частина друга статті 15 Цивільного кодексу України» (у тексті) або «ч. 2 ст. 15 ЦК
  України» (у дужках, переліках). Уперше — повна назва акта.
- Посилання на практику: «постанова Верховного Суду у складі колегії суддів Касаційного цивільного суду від
  ДД.ММ.РРРР у справі № ___ (провадження № ___)».

Часті помилки (не → так):
| Неправильно | Правильно |
|---|---|
| приймати участь | брати участь |
| на протязі | протягом |
| згідно закону | згідно із законом / відповідно до закону |
| являється | є |
| співпадати | збігатися |
| слідуючий | наступний |
| у відповідності з | відповідно до |
| прийняти міри | вжити заходів |
| задати питання | поставити питання |
| по закінченню | після закінчення |
| ставити до відома | повідомляти |
